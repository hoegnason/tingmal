Tingmál

Documents, acts and proceedings of Løgtingið, the Faroese parliament, encoded as TEI/XML with a sentence-level JSONL export.

Rani Høgnason Hansen

An unofficial dataset. Not a publication of Løgtingið.

  • Code
  • CC BY 4.0

Tingmál collects parliamentary questions, legislative proposals, laws, committee reports, decisions and coalition agreements from Løgtingið and encodes each one as a TEI P5 XML document, with every sentence carrying a stable identifier and a language tag. sentences.jsonl is the deduplicated set of all Faroese sentences, one JSON object per line, intended for text mining, parliamentary analytics, search experiments and Faroese language modelling.
